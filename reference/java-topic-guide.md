# Java Topic Guide (Grounded in `JAVA FILE.docx`)

Baseline topics observed across the 44 programs in `JAVA FILE.docx`:
1. Basics & Operators: Hello World, primitive data types, arithmetic, relational, logical, conditional, assignment, bitwise, ternary operators, constants, variables, widening/narrowing, ASCII values.
2. Control Flow & Patterns: `if`, `if-else`, `if-else` ladder, nested `if`, `switch`, multiple `switch`, `for`, `while`, `do-while`, `break`, `continue`, `return`, star/number patterns (Patterns 1–3), decimal-to-binary conversion.
3. Arrays & Matrices: 1D array creation/display, 2D matrix operations.
4. Methods & Semantics: Pass-by-value (primitives) and object reference passing (reference value semantics), method overloading.
5. OOP & Inheritance: Class and object modeling (e.g., Car example), method overriding, dynamic method dispatch, method overriding with `throws`, single inheritance, multilevel inheritance, hierarchical inheritance.
6. Interfaces & Multiple Inheritance: Multiple inheritance via `implements` with multiple interfaces, interface inheritance via `extends`.

Target difficulty ("one notch above baseline"):
- Combine 2–4 baseline concepts into cohesive, scenario-driven programs (e.g., payroll with multilevel inheritance + overriding, billing system with menu + validation + methods, smart devices with multiple interfaces + dynamic dispatch).
- Use `public class Main` in `Main.java` with package-private helper classes/interfaces.
