# C Topic Guide

Note: The 39-program C practical reference file described in PRD Section 3 was not present in `i:\` during preparation. This guide reflects the PRD Section 5 specification.

Core scope:
- Arrays: traversal, insertion, deletion
- Searching & Sorting: linear search, binary search, bubble sort, insertion sort, selection sort
- Structures & Pointers: `struct`, pointer arithmetic, dynamic memory (`malloc`/`calloc`/`free`)
- Linked Lists: singly linked list, doubly linked list (insert, delete, search, update, display)
- Stacks & Queues: array-based and linked-list stacks, infix/postfix conversion & evaluation, linear/circular/linked queues
- Trees: binary search tree (BST) insertion, search, deletion, traversals (inorder, preorder, postorder)
- File Handling: `fopen`, `fread`/`fwrite`, `fprintf`/`fscanf`, record persistence and filtering

Target difficulty:
- Level 3 (Default): 3–4 concepts integrated into a clean, menu-driven practical with input validation, boundary checks, and proper memory/file cleanup.
- Level 4 (On request): Multi-stage scenarios with interacting structures/algorithms while remaining appropriate for a BCA practical.
